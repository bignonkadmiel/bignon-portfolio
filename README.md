## Déploiement GitHub Pages

Ce portfolio est automatiquement déployé sur GitHub Pages. Pour y accéder :

1. Allez sur votre repository GitHub
2. Allez dans **Settings → Pages**
3. Sélectionnez **main** comme branche source
4. Votre site sera disponible à : `https://[votre-username].github.io/bignon-portfolio`

## Personnalisation

### Modifier les informations personnelles
Éditez les sections dans `index.html` :
- Changez "bignon@email.com" par votre email
- Mettez à jour le téléphone et la localisation
- Remplacez les liens des réseaux sociaux

### Ajouter vos projets
Dupliquez les cartes de projets dans la section `#projets` et modifiez :
- Titre du projet
- Description
- Icônes et couleurs

### Personnaliser les couleurs
Modifiez les variables CSS dans `styles.css` :
```css
:root {
    --primary-color: #6366f1;
    --secondary-color: #8b5cf6;
    /* ... */
}
```
